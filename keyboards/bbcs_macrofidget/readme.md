# bbcs_macrofidget

![bbcs_macrofidget](todo)

Key fidget in the shape of the BuildingBloCS logo, but it actually works as a macropad

- Keyboard Maintainer: [frosetrain](https://github.com/frosetrain)
- Hardware Supported: Seeed Studio XIAO RP2040
- Hardware Availability: [Official store](https://www.seeedstudio.com/XIAO-RP2040-v1-0-p-5026.html)

Make example for this keyboard (after setting up your build environment):

    make bbcs_macrofidget:default

Flashing example for this keyboard:

    make bbcs_macrofidget:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader in 2 ways:

- **Bootmagic reset**: Hold down the top key and plug in the keyboard
- **Physical reset button**: Hold down the BOOT button (labelled B) on the Seeed XIAO while plugging in the keyboard
